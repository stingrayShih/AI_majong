# 🀄 AI 台灣麻將實戰策略輔助工具 (AI_majong)

一款專為**台灣 16 張麻將**（含純化 34 種合法牌張）設計的 Android 專業實戰輔助與走勢覆盤 App。  
結合 **CameraX 4K 高畫質相機辨識**、**嚴謹台麻順位狀態機**、**Room SQLite 本地持久化** 與 **vLLM 官方雲端 API (`d3-turbo` 27B)**，提供手牌向聽、即時聽牌看板、吃碰槓決策建議與逐巡步進覆盤檢討！

---

## 📥 下載與安裝 (Installation)

> [!TIP]
> **一般使用者無須自行編譯原始碼，可直接下載安裝檔：**
> 
> 前往本專案 GitHub 的 **[Releases 頁面](https://github.com/stingrayShih/AI_majong/releases)**，即可找到最新釋出的 `.apk` 安裝檔案直接下載並安裝至 Android 手機。

### 安裝須知
1. **系統需求**：支援 Android 8.0（API Level 26）以上之 Android 手機或平板。
2. **未知來源安裝**：若下載後系統提示「未知來源應用程式」，請至手機「設定 ➔ 安全性」或瀏覽器權限中開啟「允許安裝未知應用程式」。
3. **相機權限**：首次使用相機拍照辨識手牌時，請允許相機權限；若未授權亦可從相簿選取照片或使用手動選牌開局。

## ✨ 核心特色與實裝功能

### 1. 🎯 即時聽牌看板 (Real-time Tenpai Board)
- 當手牌處於聽牌狀態時，畫面即時彈出金色看板，顯示目前所聽之牌面。
- **全場殘牌動態扣除**：即時扣除自己手牌、四家副露與四家牌河，精準回報每張聽牌「場上剩餘張數」。

### 2. 📸 高畫質手牌辨識 (CameraX + 視覺微調)
- **4K / UHD 超高解析度取景**：鎖定最高原生感應器解析度（3840×2160 優先），大幅提高 16 張牌面字跡辨識率。
- **3A 收斂與點擊螢幕手動對焦 (Tap-to-Focus)**：拍攝前鎖定自動曝光與自動對焦，杜絕手震與模糊。
- **無黑邊等比裁切框 (1:1 Pixel Mapping)**：手牌導引框精準貼合照片本體，消除 Letterbox 黑邊座標位移。
- **拍後可視化校對**：辨識完成後可單張替換、刪除與補足，確保 16/17 張手牌符合標準始可開局。

### 3. 🤖 vLLM 官方雲端決策端點 (無需自架 GPU)
- 直連官方雲端 API (`https://decision.vllm-sr.ai/v1/systemone`)，預設採用 **27B 旗艦決策模型**。
- 提供 API Key (`sk-vsr-...`) 設定與中央彈窗 Ping 連線測速。
- 內建離線智慧規則引擎備援，無網路環境亦可完整使用。

### 4. 🀄 嚴格台灣 16 張麻將規則狀態機
| 規則模組 | 機制說明 |
| :--- | :--- |
| **四家自由選莊** | 開局可自由指定 我 / 下家 / 對家 / 上家 當莊；若自己當莊起手 17 張且首輪直接出牌；對局中可隨時換莊。 |
| **嚴格順位防呆** | 輪到誰誰才能動作；未摸牌或副露前手牌處於安全鎖定狀態，杜絕誤打牌。 |
| **吃牌順位限制** | **僅允許吃上家打出的牌**；下家與對家出牌嚴格禁止吃牌。 |
| **吃牌搭子精選** | 記錄他家吃牌時，自動列出所有合法順子搭子（如 `[1萬, 2萬, 3萬]`）供點選，精準扣除牌張。 |
| **跳家與摸打順序** | 碰牌、明槓、吃牌副露後，順位瞬間跳轉至該家，打出一張牌後由其下家接續摸打。 |
| **暗槓與補槓** | 支援手牌 4 張暗槓（槓尾補牌再打牌）及他家補槓（加槓）；他家暗槓顯示 4 張玉石牌背。 |
| **搶槓判定** | 他家補槓時，若手牌符合聽牌且聽該補槓牌，系統自動偵測並提示搶槓胡牌！ |
| **胡牌二分法** | 「🟢 自摸胡牌」與「🔴 抓放槍 (榮和)」獨立按鈕，吃碰槓當回合嚴格禁止胡牌。 |
| **4 張配額鎖定** | 磁磚選擇器即時計算手牌 + 牌河 + 副露；達到 4 張上限自動反灰鎖定，杜絕第 5 張牌。 |
| **海底流局 (🀄)** | 無人胡牌時可一鍵宣告海底流局，結束對局並封存紀錄。 |
| **↩ 隨時復原 (Undo)** | 支援全狀態堆疊復原，隨時回退誤觸操作。 |
| **系統返回鍵支援** | 物理/手勢返回鍵精準對應左上角返回箭頭，避免誤觸直接退關 App。 |

### 5. 📜 Room SQLite 本地歷程持久化與逐巡覆盤 (Replay Engine)
- **本地 SQLite 永續儲存**：完賽（自摸勝、抓放槍勝、放槍、他家胡牌、海底流局）自動寫入資料庫，關閉 App 重啟永不丟失。
- **專業逐巡覆盤畫面 ([`GameReplayScreen`](file:///app/src/main/java/com/aimajong/app/ui/screens/GameReplayScreen.kt))**：
  - **進度控制**：提供 `|◀ 開局`、`◀ 上一步`、`▶️ 自動播放 / 暫停`、`下一步 ▶`、`末局 ▶|` 與步數滑桿。
  - **場況精確還原**：隨步數滑動即時呈現**自家當時手牌**、**自家副露**與**四家當時牌河**。
  - **時間軸點擊跳轉**：底部完整動作清單高亮當前步數，點選任一步驟秒級即時跳轉。

## 🏗️ 本地編譯與建置 (For Developers)

若需自行編譯開發版 APK，請確保本機已安裝 **JDK 17 或 JDK 21**：

```powershell
# 1. 複製專案
git clone https://github.com/stingrayShih/AI_majong.git
cd AI_majong

# 2. 執行單元測試 (含麻將規則驗證與覆盤引擎測試)
./gradlew testDebugUnitTest

# 3. 建置 Debug APK 安裝檔
./gradlew assembleDebug
```

編譯完成的 APK 檔案位置：
`app/build/outputs/apk/debug/app-debug.apk`
