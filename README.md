# 🀄 AI 台灣麻將實戰策略輔助工具 (AI_majong)

一款專為**台灣 16 張麻將**（含花牌）設計的 Android 實戰策略輔助 App。
直接串接 **vLLM Decision 3.0 (`d3-turbo` 27B) 官方雲端 API**（`https://decision.vllm-sr.ai`，無需自架伺服器），即時分析手牌效能、防守向聽與鳴牌勝率機率分佈。

---

## 📱 核心功能與已實裝麻將規則

- **四家自由選莊**：開局可自由指定 我 / 下家 / 對家 / 上家 當莊；若自己當莊起手 17 張且首輪先攻直接出牌；對局中可點擊頂部標籤一秒換莊。
- **嚴格順位狀態機**：
  - `AWAITING_DRAW`：輪到的玩家摸牌（若為花牌自動補花並槓尾補摸）。
  - `AWAITING_DISCARD`：手牌滿 17 張有效牌時出牌（未摸牌前嚴格鎖定防呆）。
  - `AWAITING_CALL_RESPONSE`：任何一家打牌後進入鳴牌判定。
  - `GAME_OVER`：宣告胡牌後整局鎖定，防止誤觸。
- **吃碰槓順位跳轉**：
  - **嚴格吃牌限制**：只有上家出牌時才允許吃牌；下家與對家出牌禁止吃牌。
  - **具體吃牌順子搭子點選**：記錄他家吃牌時，自動列出所有合法順子搭子（如 `[1萬,2萬,3萬]`），精準扣除牌張。
  - **跳家規則**：某家鳴牌副露後，順位瞬間跳轉至該家，打出一張牌後再由其下家接續。
- **副露當回合禁止胡牌**：吃碰槓該回合處於必須出牌階段，系統嚴格禁止在該回合宣告胡牌。
- **胡牌直覺二分**：將「🟢 自摸胡牌」與「🔴 抓放槍 (榮和)」拆分為專屬獨立按鈕與對話框。
- **暗槓功能**：手牌有 4 張相同且輪到自己出牌時，AI 提供暗槓推薦，點擊後槓尾補牌再出牌。
- **花牌防呆**：花牌不能打出，亦不能參與吃碰槓，起手手牌嚴禁選入花牌。
- **全場 4 張上限配額**：磁磚選擇器即時扣除全場可見牌數（手牌 + 牌河 + 副露），滿 4 張自動反灰鎖定，杜絕第 5 張牌。
- **↩ 復原上一步 (Undo)**：頂部導航列支援隨時回滾操作。
- **對局記憶與中斷恢復**：首頁常駐「▶ 繼續進行中的牌局」大卡片，搭配 `rememberSaveable` 跨 App 切換不中斷。
- **相機拍照辨識起手牌 (CameraX)**：實裝拍照取景、水平導引框、相簿匯入與拍後手牌校對微調介面。
- **vLLM D3 官方雲端 API**：連線官方雲端端點 (`https://decision.vllm-sr.ai/v1/systemone`)，預設採用 **27B 旗艦模型 `d3-turbo`**（亦可選用 9B `d3-flash`），具備更高之視覺與決策辨識精準度！無需自架伺服器，輸入 API Key (`sk-vsr-...`) 即可使用！

## 💻 技術堆疊

- **語言**：Kotlin 2.0+
- **UI 框架**：Jetpack Compose (Material3)
- **非同步與狀態流**：Kotlin Coroutines & StateFlow
- **本地資料庫**：Android Room 2.6.1 + KSP 代碼生成 (SQLite 持久化)
- **建置工具**：Gradle 8.9 (Kotlin DSL + Version Catalog)
- **相機框架**：CameraX 1.4.0 (Lifecycle, Camera2, View)
- **決策模型端點**：vLLM Semantic Router Decision 3.0 官方雲端 API (`https://decision.vllm-sr.ai/v1/systemone`)，API Key 格式 `sk-vsr-...`
